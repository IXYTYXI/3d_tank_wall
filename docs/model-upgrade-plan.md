# 战场模型升级

用户要求树、敌方坦克、障碍、反坦克锥和指挥所采用有辨识度的完整模型，不再使用可见的基本方块占位。

## 设计
- 程序化模型采用确定性几何，复用材质、缓存网格并按材质合并静态部件。
- 针叶树：弯曲分段树干、放射分枝、多层细碎针叶；六种外形，大小与朝向变化。
- 岩体和远山：不规则环形顶点与破碎表面，替换盒状岩石和规则圆锥山体。
- 防线：有底座、斜面的混凝土路障、龙牙反坦克锥、真实工字钢拒马，配筋/螺栓/警示纹/磨损。
- 指挥所：斜墙混凝土堡垒、屋檐、装甲入口、观察窗、沙袋、格构通信塔、抛物面天线和旗帜。
- 敌军继承已验证的完整坦克底盘、动态履带与炮口，加入阵营迷彩与三类轮廓区别；合并静态零件，保持炮塔和履带独立活动。
- 物理障碍使用匹配的凸体或分段碰撞；针叶/远山不碰撞。寻路读取各种静态形状包围盒，仍保留可通行道路。

## 完成与验证

已实现环境与敌军模型、碰撞和寻路适配。新增 18 项模型检查及 8 项实景碰撞检查，总计 133 项自动检查。实景截图覆盖正常驾驶、敌军三种轮廓、指挥所、针叶树、龙牙及拒马。修复了混用有索引/无索引网格时合并漏面，以及薄板倒角翻面问题。

静态部件按材质合并；针叶树在 100 米处使用简化外形。Apple M4 本地四辆精细敌军的短时渲染样本约 112 帧/秒，仅代表该视角下的渲染采样，不是完整战斗或其他设备的帧率保证。
