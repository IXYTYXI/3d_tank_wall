钢铁战场 0.4.0 — Windows 64 位试玩版

安装与启动
1. 将 ZIP 完整解压到一个文件夹。
2. 双击 SteelFront.exe，无需安装 Godot。
3. SteelFront.exe 和 SteelFront.pck 必须留在同一文件夹，不要直接从压缩包运行。

高画质模式
完整解压后双击 HighQuality.cmd，开启环境遮蔽、体积雾和辉光。需要支持 Vulkan 的现代显卡与驱动；若不能启动，请使用 SteelFront.exe 兼容模式。

本包未做代码签名，Windows 可能显示未知发布者提示。请核对本项目 GitHub Release 来源及 SHA-256，不要关闭系统安全保护。

玩法
基地防守：守住基地并击退五波共 18 辆敌军。玩家或基地被毁即失败。
无尽生存：挑战连续波次，波间三选一强化，坦克被毁时结算。
限时歼灭：180 秒内击毁 12 辆敌军；暂停不扣时间，任务开始前有 5 秒准备。
自由训练：练习驾驶、瞄准和射击六个训练靶。

操作
W/S 前进倒车，A/D 车体转向，鼠标瞄准。
左键或空格开火，右键开镜，滚轮调整镜头，Shift 制动。
E 应急维修（战斗中，每局两次），Esc 暂停，R 回主菜单。
关闭窗口或 Alt+F4 退出。

兼容与验证
目标平台：Windows 10/11，Intel / AMD 64 位处理器，支持 OpenGL 3.3 的显卡和驱动。
已在 macOS 完成交叉导出、Windows PE 架构检查与导出资源回归检查；尚未在 Windows 实机验证启动、画面与输入。
当前为单机原型，无存档或联网；重开清除本局强化和分数。
