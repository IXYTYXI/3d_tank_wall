# 0.4.2 玩家自主更新

用户授权在主页面添加更新选项，并更新指定飞书指南的链接与附件。

主菜单右下角展示版本、检查更新和下载页。仅玩家点击时请求仓库的公开静态版本清单 docs/latest-release.json，12 秒超时、1 MiB 响应上限。数字版本比较，忽略草稿和无本平台包的版本，包含现有 preview 发布。仅接受本仓库 GitHub 下载链接。检测到新版后由用户点击在浏览器下载，退出游戏后按平台替换；不覆盖运行中文件。

失败状态可重试并保留下载页入口。独立 game_update.gd 负责网络与版本解析，hud.gd 负责状态和按钮。离线回归覆盖版本排序、响应错误、平台选择、草稿及外部下载链接过滤。实际 UI 截图及在线清单检查另行验证。静态清单避免匿名 GitHub API 每小时限流；后续发版须同步清单版本与两端资产链接。

交付 0.4.2 Mac/Windows 安装包及飞书原文桌面下载区更新，网页游戏介绍和媒体保持原状。文档明确桌面为独立单机版本，避免将网页联机能力误写进桌面包。
