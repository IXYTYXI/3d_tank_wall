# 第三人称坦克原型实施计划

目标：一辆坦克在起伏地形中驾驶，独立炮塔瞄准，真实炮口发射并击中掩体或靶标。
技术：Godot 4.7.2 标准版、GDScript、Compatibility 渲染。首先在本机 macOS 验证。
范围依据：用户已确认第三人称原型、桌面优先、先玩法后精细资产，并授权继续。

## 模块与验收
- [x] 环境：下载官方引擎到被忽略的 work/tools；检查版本，保留仓库无引擎二进制。
- [x] tests/run.gd：先定义弹道重力、俯仰限位、最近遮挡和炮口发射回归测试。
- [x] scripts/combat_math.gd：纯弹道及瞄准计算；以实际炮管方向发射，不以相机直接造成伤害。
- [x] scripts/battlefield.gd：程序生成有真实碰撞的坡地、岩石、掩体、静止靶标。
- [x] scripts/tank.gd：CharacterBody3D 驾驶，车体 yaw 与炮塔分离，坡面姿态、重力和碰撞。
- [x] scripts/tank_visual.gd：可替换程序模型，轮组、履带、炮塔、炮口挂点。
- [x] scripts/main.gd：镜头、输入、炮弹、命中、暂停/恢复、重置。
- [x] scripts/hud.gd：驾驶信息、装填提示、目标与炮口准星、瞄准镜、进入与暂停界面。
- [x] 验证：无头导入、数学/物理回归、启动真实窗口、截屏检查、驾驶与射击输入检查。
- [x] README.md：启动方式、控制说明、原型限制、平台验证范围。

## 测试场景
1. 平地前进倒车转向，松开按键减速，爬坡保持碰撞。
2. 不驾驶时鼠标旋转炮塔，车体方向保持；炮塔转速和俯仰受限。
3. 背靠墙时镜头缩回，移开后恢复；镜头排除本车。
4. 相机看见远方但炮口被掩体挡住时，炮弹命中近处掩体。
5. 高速炮弹在前后位置间扫掠，不能穿过薄墙；地形高低差参与命中。
6. 按住开火遵守装填时间；暂停后不继续移动或发射；恢复不残留鼠标跳变。
7. 击中靶标显示反馈；R 重置战场；越界或翻落时可恢复。

不推送、不部署。联网、账号、职业、移动端触控和正式资产不属于本轮。
