# 三模式与 macOS 试玩版计划

用户已确认：基地防守优先，再加入无尽生存与限时歼灭，封装 Mac 安装包并提供下载链接。

- 保留基地防守五波循环、自由训练、中文和现有键位。
- 无尽生存：没有基地，持续波次，每波清空后强化；敌军数量逐渐增加至每波 12 辆，同时最多 4 辆。出生区域固定在地图内。玩家被毁后结算波数、击毁和得分。
- 限时歼灭：没有基地，180 秒内击毁 12 辆敌军。保持最多 4 辆，持续补充，限时或玩家死亡则失败，12 杀获胜。暂停不扣时间。没有波间强化。
- 新模式使用同一导演的模式参数和同一物理战斗系统；敌军无基地时始终以玩家为目标。HUD、菜单、结算按模式展示，不访问空基地。
- 主菜单提供三种战斗和训练入口，显式显示目标；基地防守为主按钮。
