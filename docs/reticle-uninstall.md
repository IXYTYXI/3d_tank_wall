# 0.4.3 准星与 Windows 卸载入口

用户澄清：瞄准不能随炮塔移动，初始画面准星不再移动。代码确认主白色十字固定于 viewport 中央，预测落点只有黄圈。本次把主十字移到炮口预测落点，中央目标保留小点，不改变相机射线和炮塔跟随关系，避免反馈循环。新增投影回归、实际转动与稳定后截图。

Windows 便携卸载器先校验同目录包标记，再要求 Y/N 确认，检测游戏运行，按明确文件列表删除主程序、资源、启动入口和说明；检查是否残留失败后才移除标记和自身。不递归删除文件夹，不强杀进程，不扫描其他目录。第三方许可、个人文件及日志缓存保留。支持文件被锁导致的部分卸载后再次运行。只有包静态验证，没有 Windows 原生执行环境，不能声称实机卸载测试通过。
