# 0.4.4 瞄准输入兼容

用户确认 0.4.3 的 WASD 驾驶可用，鼠标操作只放大，早期两个版本没有问题。未得到 Windows 原始输入事件，故不声称已确认这台机器的根因。

对比 9d0dd4d、03506c5、0.3.0 和 HEAD：玩家模型的炮塔层级和角度求解没有后续变动。0.4.1 将鼠标位移从 relative 改为只读取 screen_relative。新测试只发送 relative、screen_relative 为零，旧版本忽略移动，实际炮塔不转；这是可复现的兼容缺口。

修正：恢复 relative 通道，并将视口缩放换算回屏幕像素。若 relative 为空才使用 screen_relative，避免双重计数；保留 _input 接收优先级、暂停与失焦门禁。新增方向键瞄准作为独立输入路径，HUD 显示炮塔与车身夹角。未改动炮塔模型或射击方向算法。

回归：tests/aim_compatibility.gd 修改前 7 项失败。测试通过真实 Input / Viewport 事件与主循环，检查实际炮塔节点、车身方向和同时操作；不直接设置炮塔旋转。还运行原有鼠标输入/游戏规则检查，以及两端导出 PCK 中相同测试。

限制：本机是 macOS，没有 Windows 运行环境。不能据此称原始 Windows 故障已实机解决。鼠标仍未恢复时，可以直接用方向键瞄准和空格开火。

本轮验证结果：14 项瞄准兼容检查通过；完整 scripts/check.sh 通过；macOS 与 Windows 导出资源检查通过。Mac 图形模式同样 14 项通过，并截图确认炮塔相对车身左转 38° / 右转 61°。测试注入输入事件，不能代替 Windows 设备驱动实测。
